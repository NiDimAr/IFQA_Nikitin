Проект для тестирования API и работы с Cucumber + RestAssured + Allure.

## Используемые технологии

Java 17, Maven, RestAssured, Cucumber (русские шаги), Allure для отчетов, JUnit 5

## Запуск тестов

1. Cтянуть проэкт:
   git clone https://github.com/SNVKEZ/ForIFellowSchAT
2. Перед тестами запустить RUN

## Описание тестов

1. Полный цикл аутентификации пользователя
2. Проверка логина с неверным паролем и логином
3. Тесты API Rick and Morty
